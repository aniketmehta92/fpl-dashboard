# fpl-dashboard

Published view of a personal Fantasy Premier League dashboard, generated by a
local analyst agent and served via GitHub Pages.

`index.html` is a self-contained static page — inline CSS and JS, no external
requests, no build step, no dependencies.

## What is in this repo

Only `index.html`, this README, and `.gitignore`. Nothing else is ever
committed. The `.gitignore` denies everything by default and allow-lists the
handful of files above, so credentials, API tokens, MCP configuration and
agent state cannot reach this repo even by accident.

The page contains squad selections, expected-points projections and fixture
difficulty ratings. It contains no account identifiers, tokens or contact
details.

## Updating

Regenerated and pushed automatically at the end of each analyst run via
`publish-dashboard.ps1`.
